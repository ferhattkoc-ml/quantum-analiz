# Security Policy

## Reporting Vulnerabilities

If you believe you have found a security vulnerability in this project, please **do not** open a public issue. Instead, please report it via email to:

**ferhatkoc154@gmail.com**

We appreciate your effort in helping us maintain the security and integrity of our systems. We aim to acknowledge receipt of your report within 48 hours and work toward a remediation plan as quickly as possible.

## Security Practices

*   **Communication:** All vulnerability reports are treated as strictly confidential.
*   **Remediation:** We are committed to patching critical vulnerabilities within a reasonable timeframe based on risk severity.
*   **Disclaimer:** This repository is a **showcase**. It intentionally excludes production infrastructure configurations, credentials, and sensitive business logic. The security of this public showcase is not representative of our production environment.
